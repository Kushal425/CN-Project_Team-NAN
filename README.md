# NAN — Computer Networks Phase 1

## Project Overview

NAN is a distributed local-network web service demonstrating core computer-networking concepts using four macOS machines connected to the same Wi-Fi LAN.

The system contains:

- A local DNS server using dnsmasq
- An Nginx reverse proxy and load balancer
- Two HTTP backend servers
- Local HTTPS using a private Certificate Authority
- HTTP caching headers
- Load balancing and backend failure testing
- Wireshark packet captures for network analysis

## Nginx Reverse Proxy

Nginx acts as the gateway and reverse proxy.

The upstream group contains:

10.7.20.70:3001
10.7.0.210:3002

Nginx forwards incoming requests to these backend servers.

The backend can be identified using the response header:

X-Backend: A

or:

X-Backend: B

## Backend Failure Testing

The project includes backend failure testing.

One backend can be stopped while the other backend remains available.

Requests are then sent through Nginx to observe the behavior of the load-balancing system when an upstream server becomes unavailable.

The failure scenario was also captured using Wireshark.

This demonstrates how the reverse proxy behaves when one upstream backend is unavailable.
